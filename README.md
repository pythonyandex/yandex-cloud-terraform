# Terraform инфраструктура для Yandex Cloud

## Описание
Проект развертывает инфраструктуру в Yandex Cloud:
- Виртуальная машина с Ubuntu
- Managed MySQL кластер
- Container Registry
- Сетевая инфраструктура (VPC, Security Groups)
